# 多语言 / 文案键（AI）

何时读：新增或改 `GetLang` / `TraceLang` / `LogLang` / 弹窗文案，或改 `shared/assets/.../language/zh-CN.json`。
源语言以 **`zh-CN.json`** 为准；其它 locale 后期由玩家自行翻译，AI **勿**强行同步完整键表。

路径解析：`MultiLangUtils.getLangText` 按**完整键**一次取值（键里的 `.` 不是嵌套）。

缺键回退：当前 locale → **`zh-CN`** → `[N/A]`（静默，无日志）。整包缺失时同理：非中文包加载失败仍可启动，文案全走 `zh-CN`；仅 `zh-CN.json` 失败才 init fail。

包内容文案（`packs/**/meta.json` 的 `language.zh-CN.name` / `says` 等）**不进**本文件；见 [`packs.md`](packs.md) 与 `PackLangUtil`。

---

## MUST

| # | 规则 |
|---|------|
| 1 | 新文案先写入 `zh-CN.json`，再在代码用完整键调用（`zh-CN` 是唯一完整源与运行时兜底） |
| 2 | 扁平键：一个键对应一条字符串。叶段 `snake_case` |
| 3 | 玩家界面按界面分组，不按类名。段：`common` `menu` `settings` `loading` `fight` `musou` `world_map` `lan` `credits` `update` |
| 4 | 占位符 `{name}` 与 `GetLang` / `TraceLang` / `LogLang` 的 `params` 键同名 |
| 5 | 弹窗位图标题用同键加 `.title`，正文用无后缀键；标题可保留英文 |
| 6 | 开发壳 UI → `dev.{界面}.{事件}`，走 `GetLang`，要翻译 |
| 7 | 日志文案键与 `GameLogger` 对齐：`log.{级别}.{分类}.{归属}.{事件}`。级别只许 `error` `warn` `info` `debug`；分类必须等于这次调用的 category |

## NEVER

- 业务里手写拼接玩家/调试中文（应进语言包）
- 用日志键兼作玩家可见文案（玩家文案用界面段）
- 无嵌套本地化需求时写 `Format(GetLangText(...))`（应 `GetLang`）
- 业务直接调 `KyoStringFormat`；直接 `Trace`（调试跟踪用 `TraceLang`，其它级别用 `LogLang`）
- 为对齐其它 locale 批量复制/翻译整张键表（缺键会静默用中文）
- 再写 `* 跟踪 : ` / `* 日志 : ` / `* 错误 : ` 前缀（行格式已有级别和分类）
- 把语言包写成嵌套对象

## 键形态

```
{界面}.{事件}
{界面}.{事件}.title
dev.{界面}.{事件}
log.{级别}.{分类}.{归属}.{事件}
```

| 完整键 | 含义 |
|--------|------|
| `loading.fighter_fail` | 玩家侧加载失败 |
| `musou.need_more_money` | 弹窗正文（可含 `{amount}`） |
| `musou.need_more_money.title` | 弹窗位图标题 |
| `dev.fighter_tester.show_hit_area` | 开发壳按钮 |
| `log.debug.trace.musou_ctrl.wave_end` | 调试跟踪 |
| `log.error.load.game_stage_load_ctrl.get_map_data_fail` | 抛错文案 |

日志分类沿用 `GameLogger`：`sys` `load` `fight` `net` `input` `ui` `musou` `trace`。

`TraceLang(event)` 固定为 `LogLang(DEBUG, 'trace', event)`，键是 `log.debug.trace.{event}`。

## 代码出口

| 场景 | 写法 |
|------|------|
| UI / 弹窗 / 玩家可见失败 | `GetLang(key[, params])` |
| 调试跟踪 | `TraceLang(event[, params])` |
| 其它已翻译日志 | `LogLang(GameLogger.级别, category, event[, params])` |
| 仅当 params 内还嵌另一段本地化片段 | `GetLang` 取片段 + `GetLang(模板, params)`（少见） |
| 无句子的运行时输出（堆栈、`String(e)`、json） | `GameLogger` 直接写，不进语言包 |
| `ThrowError` 的 `message` | `GetLang('log.error.{分类}.{归属}.{事件}')` |

全局封装：`Format` → `KyoStringFormat.formatNamed`；`GetLang` = `Format(GetLangText)`；`TraceLang` = `LogLang(DEBUG, 'trace', …)`。

`LogLang` 在级别高于 `GameLogger.threshold` 时不取文案。缺键或 `[N/A]` 时输出完整键。
