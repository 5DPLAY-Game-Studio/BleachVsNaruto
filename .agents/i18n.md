# 多语言 / 文案键（AI）

何时读：新增或改 `GetLang` / `TraceLang` / 弹窗文案，或改 `shared/assets/.../language/zh-CN.json`。  
源语言以 **`zh-CN.json`** 为准；其它 locale 后期由玩家自行翻译，AI **勿**强行同步完整键树。

路径解析：`MultiLangUtils.getLangText` ← 点分路径 ← `ClassUtils.continuousAccess`（`.` = JSON 嵌套）。

---

## MUST

| # | 规则 |
|---|------|
| 1 | 新文案先写入 `zh-CN.json`，再在代码用点分键调用 |
| 2 | 键路径与 JSON 嵌套一一对应；叶键 `snake_case` |
| 3 | 归属段用类名 / 场景的 snake_case（如 `GameLoader` → `game_loader`，`WorldMapStage` 场景块 → `world_map`） |
| 4 | 占位符 `{name}` 与 `GetLang` / `TraceLang` 的 `params` 键同名 |
| 5 | 弹窗位图标题（`font1`）用 `*_title`，正文用同名无后缀键；标题可保留英文 |
| 6 | 玩家可见短文案 → `txt.*`；弹窗 → `alert.*` / `confirm.*`；调试 → `debug.trace|log|error.*`；开发壳 → `dev.txt.*` |

## NEVER

- 业务里手写拼接玩家/调试中文（应进语言包）
- 用 `debug.log.*` 兼作 `fail(...)` / 玩家可见文案（对齐 `txt.*`，参见 `GameLoader`）
- 无嵌套本地化需求时写 `Format(GetLangText(...))`（应 `GetLang`）
- 业务直接调 `KyoStringFormat`；直接 `Trace`（调试跟踪用 `TraceLang`）
- 为对齐其它 locale 批量复制/翻译整棵键树

---

## 用途桶（第一段）

| 前缀 | 用途 | 出口 API |
|------|------|----------|
| `txt.*` | 玩家可见短文案、加载失败提示、菜单 cn 等 | `GetLang` |
| `alert.*` | 警告弹窗正文 / `*_title` | `GetLang` → `GameUI.alert` |
| `confirm.*` | 确认弹窗正文 / `*_title` | `GetLang` → `GameUI.confrim` |
| `debug.trace.*` | 调试跟踪（含 `prefix`） | `TraceLang` |
| `debug.log.*` | `Debugger.log` 类日志 | `GetLang` |
| `debug.error.*` | `throw` / `ThrowError` 消息 | `GetLang` |
| `dev.txt.*` | 开发壳 UI（如 `FighterTester`） | `GetLang` |

`debug.{trace\|log\|error}` 下结构：`prefix` + `data.{归属}.{事件}`。

---

## 键形态

```
用途[.通道].归属.事件
```

| 完整键 | 含义 |
|--------|------|
| `txt.game_data.load_fighter_fail` | 玩家侧加载失败 |
| `debug.trace.data.musou_ctrl.wave_end` | 无双波次跟踪 |
| `debug.error.data.fighter_mc.go_frame` | 抛错文案 |
| `confirm.world_map.exit_title` | 弹窗位图标题 |
| `alert.musou_ctrl.need_more_money` | 弹窗正文（可含 `{amount}`） |

---

## 代码出口（对齐现状）

| 场景 | 写法 |
|------|------|
| UI / 错误 / fail | `GetLang(path[, params])` |
| 调试跟踪 | `TraceLang(path[, params])` |
| 仅当 params 内还嵌另一段本地化片段 | `GetLang` 取片段 + `GetLang(模板, params)`（少见） |
| 开发壳硬编码日志 | `Trace(模板, params)` |
| `ThrowError` 内部英文诊断 | `Printf`（不进语言包） |

全局封装：`Format` → `KyoStringFormat.formatNamed`；`GetLang` = `Format(GetLangText)`；`TraceLang` = `Trace(GetLang)`。
